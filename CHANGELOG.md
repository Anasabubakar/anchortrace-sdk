# Changelog

## 0.1.0 (unreleased)
First version-one scope.
- SEP-24 (v3.8.0) record normalisation: 16 statuses, kind-aware expectations, deposit and withdrawal legs, refunds, amount formulas.
- Classic direct payment evidence from supplied Horizon-shaped files and live read-only Horizon reads (plain `fetch`, timeouts, size cap).
- Operation-level matching: destination, asset code and issuer, exact 7-decimal amounts (bigint stroops), memo, sender; ambiguity for multi-operation transactions; path payments, claimable balances and Soroban transfers reported as unsupported.
- Explicit fee policy (`anchor_deducted`, `customer_paid_on_top`, `no_fee`) and basis-point tolerance.
- Deterministic timelines for duplicate and reordered status updates, with conflicts reported as findings.
- Provenance per input, redacted exports, JSON report with published JSON Schemas, text/markdown/explain renderings, `anchortrace` CLI.
- Real Stellar testnet evidence fixtures and 18 example cases generated by the engine.
